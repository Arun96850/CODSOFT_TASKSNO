# 🛡️ PhishGuard - Phishing Awareness Website

## 📌 About the Project

PhishGuard is a simple Phishing Awareness Website designed to educate users about phishing attacks and online safety.

## 🎯 Objectives

- Understand what phishing is
- Identify suspicious links and emails
- Learn how to protect personal information
- Test phishing awareness through an interactive quiz

## ✨ Features

- Phishing Awareness Information
- Phishing Safety Tips
- Interactive Quiz
- Correct/Wrong Answer Feedback
- Score Display
- Quiz Progress Bar
- Restart Quiz Option
- Responsive Design
- Navigation Bar
- Footer Section

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
