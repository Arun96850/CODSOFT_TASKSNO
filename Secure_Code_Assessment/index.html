🛡️ Security Assessment

⚠️ 1. Hard-coded Credentials

Username and password are directly written in the JavaScript code.

Risk: Credentials can be exposed if the source code is accessed.

Fix: Store credentials securely and avoid hard-coding them.

⚠️ 2. Weak Password

A simple password such as admin123 is easy to guess.

Risk: Attackers may guess weak passwords.

Fix: Use strong passwords with a proper password policy.

⚠️ 3. Insecure Password Handling

The password is compared directly in client-side JavaScript.

Risk: Users can inspect the source code and see the login logic.

Fix: Perform authentication on a secure server and use password hashing.

✅ Security Recommendation

Use secure authentication, strong passwords, server-side validation, and password hashing to improve application security.
